The last text message a phone sends at one percent battery, in the phone's own voice: a dying phone hands in its two weeks' notice — four years, eleven drops onto concrete, zero thank-yous — and quits mid-sentence. `main.py` (Python stdlib only) writes the 156-character message to `/output/entry.txt`, deterministically.

## Run it

```sh
python3 main.py
```
